# LangPartGPD

## LangPartGPD
1. Clone this repository:
    ```bash
    cd $HOME/code
    git clone https://github.com/aaronhd/LangPartGPD.git
    ```

2. Install our modified dex-net (Modify from [Berkeley Automation Lab: dex-net](https://github.com/BerkeleyAutomation/dex-net))
    ```bash
    cd $HOME/code/PointNetGPD/dex-net
    python setup.py develop
    ```

3. LangSHAPE dataset is available from [project website](https://sites.google.com/view/lang-shape/dataset)
